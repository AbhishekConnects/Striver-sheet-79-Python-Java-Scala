# Python Data Structures and Algorithms

## Project Structure

- **array_hashing/** - Array operations and hash table problems
- **binary_search/** - Binary search algorithms and variations
- **linked_list/** - Singly, doubly linked lists and operations
- **recursion_backtracking/** - Recursive solutions and backtracking problems
- **stacks_queues/** - Stack and queue implementations and problems
- **heaps/** - Min/max heaps and priority queue problems
- **trees/** - Binary trees, BST, and tree traversals
- **graphs/** - Graph algorithms (BFS, DFS, shortest path)
- **dynamic_programming/** - DP problems and optimization
- **tries/** - Trie data structure and string matching
- **strings/** - String manipulation and pattern matching

Each folder contains Python implementations with test cases.
